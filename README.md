# Cura Parásitos

Investigación forense de antiparasitarios farmacéuticos y naturales: dosis publicadas, nivel de evidencia, resistencia, diagnóstico previo y señales de alarma.

- `index.html`: sitio web estático (fondo blanco, estilo Apple).
- `reports/`: informe completo en Markdown.
- `research_notes/`: notas de investigación por tema.
- `SUPER-PROMPT.md`: el prompt usado para la investigación.

> Aviso médico: síntesis informativa. No es consejo médico ni sustituye la evaluación de un profesional de salud. Verifique dosis con la ficha oficial del ISP/MINSAL. No se automedique.
